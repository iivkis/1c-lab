# Выгрузка лабораторной работы

Положите сюда **единственную** итоговую выгрузку учебной информационной базы 1С:

`artifacts/warehouse.dt`

Файл `.dt` ещё **не создан** и не должен заменяться пустой заглушкой. CI запускает проверку реальной 1С только после установки `ONEC_TRAINING_CI=true` и настройки учебного `1cv8t` на self-hosted runner. Храните большие бинарные `.dt` через Git LFS.
