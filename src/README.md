# Исходники 1С:Предприятие

В этом каталоге находятся XML-описания метаданных и BSL-модули учебной конфигурации:

- `Configuration.xml`, `Catalogs/`, `Documents/`, `AccumulationRegisters/`;
- `CommonModules/` для складской бизнес-логики и запросов;
- `Reports/` со схемами компоновки данных для четырёх отчётов;
- `DataProcessors/` для четырёх задач, анализа данных и приёмочных проверок;
- `Subsystems/`, `Languages/` для интерфейса;
- `Forms/` внутри документов и обработок для управляемых форм.

**Важно:** файлы созданы как проектная XML-выгрузка; успешное чтение XML и анализ BSL ещё **не подтверждают**, что вся конфигурация загрузится средствами учебной 1С. Реальную проверку запускайте по [инструкции](../docs/RUN_IN_ONEC.md).
