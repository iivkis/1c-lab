# Исходный код конфигурации 1С

Здесь хранятся исходные файлы конфигурации 1С: **XML + BSL** (например, результат выгрузки конфигурации в файлы из Конфигуратора).

- Модули с расширением `.bsl` из этой папки и её подпапок проверяются в GitHub Actions через **BSL Language Server**.
- Если хотя бы в одном `.bsl` обнаружена ошибка `ParseError`, CI падает.
- Пока в `src/` нет ни одного `.bsl`, CI также падает, чтобы не выдавать ложный успех.
- Линтер не заменяет проверку метаданных и запуск конфигурации в 1С. `.dt` нужен для сдачи преподавателю, не для проверки синтаксиса.

Для первой проверки агент должен добавить сюда настоящие модули `.bsl`, а не пустые файлы-заглушки.
